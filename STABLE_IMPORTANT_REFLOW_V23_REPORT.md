# Stable Important Reflow V23

Точечное исправление V22. Второй Layout Pagination Engine не создавался.

- Автоматический прописной акцент выбирается только из текста фактически измеренной текущей страницы.
- После вставки акцента диапазон рассчитывается повторно до стабилизации переразметки.
- Для короткого остатка страницы предусмотрен запасной вариант из одного слова.
- Финальная проверка гарантирует, что выбранный диапазон остался на текущей странице.
- Ручное переполнение цитаты или заметки по-прежнему выдаёт явную ошибку.
- Исходный текст не изменяется и не режется по символам.
