# Design Pack 01 Approved — V9

## Исправления по проверке пользователя

- Пустой демонстрационный проект больше не собирается как книга: нужна реальная глава с авторским текстом, фотографией или заполненным документом.
- Дополнительные разделы и листы выключены по умолчанию. Состояние каждого листа передаётся сборщику и не сбрасывается при пересборке.
- Обложка и задняя обложка отображаются одной полной страницей в миниатюрах и предпросмотре; фиктивной соседней страницы нет.
- Предпросмотр открывается сразу в конечной геометрии: без щели у корешка, изменения масштаба и стартового движения листов.
- Замена фотографии привязана к исходному объекту фотографии, поэтому результат не зависит от смены активной карточки во время файлового диалога.
- Триптих создаётся только по явному выбору и только из трёх фотографий одного исходного листа. Фотография с другого листа не поглощается триптихом.
- Ориентация фотографии хранится при загрузке. Вертикальный кадр предпочитается для открытия; панорама на две страницы создаётся только по явному выбору.
- Пустой обычный лист главы удаляется после паузы ввода. Первый лист главы, начало нового эпизода и документ автоматически не удаляются.
- Название эпизода редактируется и на текстовом листе. Заголовок, цитата и буквица появляются только у явного начала эпизода; продолжения их не повторяют.
- Ручная цитата имеет приоритет. При её отсутствии выбирается одна автоматическая цитата и удаляется из основного набора.
- Ёмкость текстовых мастеров измеряется в DOM перед сборкой с фактическими шрифтами и размерами полос, остаток переносится по завершённым предложениям.
- Документ собирается как скан и отдельная линованная страница расшифровки/пояснения в системе Design Pack 01.
- Выпадающий список размещения фотографии перерисован в стиле карточки.
- Убраны неподтверждённые надписи «Составлено с любовью» и автоматическая подпись автора/года. Для нижней подписи обложки есть отдельное редактируемое поле.
- Встроены 11 музыкальных файлов. И автоматическая смена, и ручные стрелки сначала дают 3 секунды винила, затем запускают новую композицию; стрелки не прокручивают книгу.
- Экспорт PDF выполняется напрямую из фирменного модального окна. Диалог принтера не используется; размер страницы 280×280 мм, целевое качество 300 dpi.

## Автоматическая проверка

- Синтаксис двух модулей рендерера и всех встроенных скриптов HTML пройден.
- Пустой демонстрационный проект отклоняется.
- Триптих 3+1 сохраняет все четыре исходные фотографии.
- Выключенные листы отсутствуют в результате сборки.
- Продолжение не получает повторный заголовок эпизода.
- Прямой PDF-маршрут и модальное окно подключены; вызова `window.print()` нет.
- Мастера документа, цитаты, панорамы, триптиха, обложек и текстовых страниц проходят регрессионные тесты.

## Что проверить на Windows

В этой рабочей среде нет установленного Chrome/Edge, поэтому фактический файл PDF невозможно было отрендерить здесь. На Windows запустите `start_windows.bat`, соберите тестовую главу и нажмите PDF. Сервер автоматически использует установленный Google Chrome или Microsoft Edge. Визуально проверьте только финальную растровую чёткость фотографий и отсутствие предупреждения о слишком низком разрешении исходника.
