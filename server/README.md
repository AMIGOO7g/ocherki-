# Сервер «Очерков жизни»

Отвечает за три вещи:
- вход по коду на почту, без паролей;
- хранение книги (текст, страницы, фото) в аккаунте, чтобы её можно было открыть на любом компьютере;
- раздачу самого конструктора с того же адреса.

Без сервера конструктор тоже работает. Тогда книга хранится только в браузере на этом компьютере.

## Что нужно

1. **Сервер в России** (152-ФЗ). Подойдёт любой VPS с Linux, например Yandex Cloud, Selectel или Timeweb Cloud. Минимум: 1 ядро, 1–2 ГБ памяти, диск от 20 ГБ (фото занимают больше всего места).
2. **Node.js 22.5 или новее.** Отдельная база данных не нужна: SQLite встроена в Node.
3. **Домен и HTTPS.** Например, через nginx и сертификат Let's Encrypt. Без HTTPS вход работать не будет: cookie сессии передаётся только по защищённому соединению.
4. **Почтовый ящик для отправки кодов (SMTP).** Например, Яндекс 360 для бизнеса на своём домене, Mail.ru для бизнеса или Unisender Go.

## Запуск

```bash
cd server
npm install
export OCHERKI_SECRET="$(openssl rand -hex 32)"   # сохраните, при смене все выйдут из аккаунтов
export SMTP_HOST=smtp.yandex.ru SMTP_PORT=465 SMTP_USER=book@ваш-домен.ru SMTP_PASS=пароль-приложения
export MAIL_FROM="Очерки жизни <book@ваш-домен.ru>"
export OCHERKI_DATA=/var/lib/ocherki                # где хранить базу и фото
export PORT=8080
node server.js
```

nginx проксирует `https://ваш-домен.ru` на `http://127.0.0.1:8080` и передаёт заголовок `X-Real-IP`.

## Попробовать локально, без почты

```bash
OCHERKI_SECRET=$(openssl rand -hex 32) OCHERKI_MAIL=console OCHERKI_INSECURE_COOKIE=1 node server/server.js
```

Откройте http://localhost:8080. Код для входа появится в окне сервера.

## Резервные копии

Всё хранится в папке `OCHERKI_DATA`: файл `ocherki.sqlite` и папка `photos`. Копируйте её каждый день, например по `cron` в объектное хранилище в России.

## Безопасность

- Коды и сессии хранятся только в виде хэшей.
- Код действует 10 минут, на него даётся 5 попыток. Новый код можно запросить через минуту (кнопка с обратным отсчётом), прежний при этом перестаёт действовать. На один адрес — не больше 5 писем в час, с одного IP — не больше 10.
- Cookie сессии: `HttpOnly`, `Secure`, `SameSite=Strict`. Кроме того, все изменяющие запросы требуют заголовок `X-Ocherki`.
- Каждый пользователь видит только свои книги и фото.
