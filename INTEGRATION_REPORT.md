# Отчёт об интеграции Design Kernel v1

## Итог

Design Kernel v1 перенесён в книжный движок конструктора как детерминированная система для формата 280×280 мм. Реализованы физический порядок страниц, фиксированная сетка 1000×1000 px на страницу, типографические токены, мастера, чередование фотографий, ограничения ритма и автоматические проверки.

Полное пиксельное совпадение с `Style_Proof_v1 cloude.pdf` пока нельзя считать подтверждённым: исходный PDF целиком растровый, поэтому точные названия и метрики использованных шрифтов из него извлечь невозможно; кроме того, в текущей среде отсутствует исполняемый Chromium. Код сценария реального UI-теста приложен в папке `qa/`, но получить честные скриншоты конструктора без браузерного бинарника здесь не удалось.

## Что реализовано

- страница 280×280 мм представлена как 1000×1000 CSS px, разворот — 2000×1000 px;
- безопасное поле 70 px, зона у корешка 91 px, 12 колонок, межколонник 32 px;
- физический порядок: обложка отдельно, затем развороты 2–3, 4–5 и далее, задняя обложка отдельно;
- встроенные кириллические шрифты Cormorant для акциденции и PT Serif для набора;
- спокойный книжный кегль основного текста, уменьшенные плотные стили и ограниченный кегль цитат;
- фотографии без рамок и теней; подписи создаются только из реальных метаданных;
- поддерживаются источники изображения `src`, `dataUrl`, `dataURL`, `url`, `preview`, `objectUrl`;
- фото/текст и текст/фото чередуются детерминированно;
- большой фотографический разворот использует два независимых кадра;
- добавлен мастер документа с отдельным пояснением;
- исключены повтор мастера подряд, две плотные текстовые композиции подряд, повтор цитаты и повтор фотографии;
- заголовки глав не дублируются: при конфликте создаётся однозначный нумерованный заголовок;
- добавлена проверка переполнения DOM, рамок/теней фото, последовательности нумерации и ритма мастеров;
- обложка и задняя обложка показываются в предпросмотре как одиночные страницы.

## Автоматические проверки

Результат доступен в браузере через:

```js
window.OCHERKI_DESIGN_KERNEL_QA
window.OCHERKI_RUN_DESIGN_KERNEL_QA()
```

Проверяются:

- одинаковые мастера подряд;
- две плотные текстовые композиции подряд;
- дубли заголовков глав;
- повтор цитат и фотографий;
- подписи без исходных метаданных;
- последовательность фолио;
- повтор большого фотографического разворота;
- выход содержимого за границы страницы;
- рамки и тени вокруг фотографий.

## Что требует дополнительной доработки

1. **Визуальная сверка реального рендера.** Сценарий `qa/run_constructor_capture.js` проходит через настоящие кнопки конструктора и сохраняет каждый разворот. В этой среде он не запущен только из-за отсутствующего Chromium.
2. **Шрифтовая идентичность.** В исходном PDF шрифты не встроены как текстовые объекты. В конструкторе выбрана близкая книжная пара Cormorant + PT Serif; точное совпадение возможно только при предоставлении названий или файлов шрифтов эталона.
3. **Печатный выпуск.** Эталонный PDF не содержит 3-мм вылетов. Браузерный макет соответствует обрезному формату; отдельному PDF-экспортёру ещё потребуется добавить вылеты и печатный preflight.
4. **Пиксельный допуск.** После получения скриншотов нужен автоматический diff против эталона. До этого нельзя честно заявлять, что отличий нет.

## Проверка сборки

- JavaScript всех встроенных скриптов: синтаксически корректен;
- `master_design_01.json`: валиден;
- исходный PDF проанализирован по всем 38 страницам;
- алгоритм больше не опирается на приблизительную норму одного универсального макета для всей книги;
- QA-сценарий и его тестовые материалы включены в архив.
