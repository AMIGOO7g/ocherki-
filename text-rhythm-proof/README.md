# Текстовый ритм · мини-proof

Отдельная проба пяти текстовых нюансов. В конструктор не подключена.

Все четыре варианта построены на одной квадратной двухколоночной странице,
с одинаковыми полями, фолио и объёмом текста. На самой книжной странице нет
повторяющихся заголовков — сравниваются только редакционные приёмы:

- важная строка — умеренная рукописная пропись курсивом, без линий, чуть чаще и с более заметным тоном, в своей колонке;
- заметка — рукописная, вертикальная, только во внешнем поле и вне потока; показан также двухстрочный вариант с небольшим заходом в набор;
- цитата — короткая пауза внутри повествования без подписи;
- инициальная буква — крупная serif-буква внутри отдельного контейнера, выступает выше текста, заходит под вертикальную линию и обрезается ею; текст начинается примерно с середины буквы;
- текстовая разбивка — два блока двухколоночного набора с заголовком и цитатой по центру.

Фон книжных страниц — чисто белый. Все основные варианты используют одинаковый квадратный формат и одинаковый объём текста.

Шрифты взяты из конструктора:

- `CormorantCy` — инициаль, заголовок разбивки и цитата;
- `PTSerifCy` — основной текст;
- `SignThatS` — важная строка и заметка на внешнем поле.

Запуск: двойной клик по `open_text_rhythm_proof.bat` или открытие
`text-rhythm-proof.html` в браузере.
