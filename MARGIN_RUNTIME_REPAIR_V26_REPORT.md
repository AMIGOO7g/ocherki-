# V26 — исправление автоматической заметки `margin`

- Устранён ложный выход рукописного текста за измеряемую область: заметка получает безопасный отступ 12 px сверху и снизу внутри высоты колонки.
- Автоматическая заметка сокращается и повторно измеряется прежним единым Layout Pagination Engine.
- Если браузер всё равно не может разместить автоматическую заметку, книга продолжает собираться без потери или дублирования исходного текста; создаётся диагностическое предупреждение `ACCENT_AUTO_MARGIN_OMITTED`.
- Ручная заметка длиннее двух строк по-прежнему блокируется с просьбой сократить текст.
- Обновлены ключи кэша конструктора и Test Mode для ПК и телефона.
- Пройдено 36 JavaScript-файлов тестов и 3 серверных теста.

Критическая проверка: сообщение «Обязательный редакционный акцент „margin“ не удалось разместить» больше не является аварийным исходом для автоматического ритма страницы.
