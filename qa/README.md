# Скриншоты реального конструктора

`column-break-repro.html` — сфокусированная DOM-проверка преждевременного
разрыва колонки. Она фиксирует ошибку, если непоследняя измеряемая колонка
оставляет больше двух интерлиньяжей свободного места.

`shared-layout-browser-check.html` сравнивает результат общего Engine/Renderer
со сборкой из изолированного Test Mode на длинном тексте, фотографиях, двух
форматах и ширинах экрана ПК/телефона.

Сценарий открывает `shell.html`, передаёт тестовую структуру через `postMessage`, выбирает дизайн `editorial`, нажимает «Собрать книгу» и «Предпросмотр», затем сохраняет каждый разворот.

Запуск из корня конструктора:

```bash
node qa/run_constructor_capture.js
```

Можно указать другую папку результата:

```bash
node qa/run_constructor_capture.js ./my-screenshots
```

Требования: Node.js, пакет Playwright и установленный Chromium для Playwright. Результат — PNG каждого разворота и `manifest.json` с ошибками страницы.

Для отдельной проверки двадцати мастеров Design Pack 01:

```bash
node qa/capture_design_pack_01.js
```

Без Playwright каталог можно открыть вручную файлом `book-renderer/master-proof.html` или кнопкой `open_master_proof.bat`. В каждой строке слева находится страница исходного PDF, справа — тот же мастер нового Book Renderer.

Проверка видимых исправлений V15 без браузера:

```bash
node qa/v13_visible_output_regression_test.js
node qa/v14_reference_composition_regression_test.js
node qa/v15_reference_composition_regression_test.js
```

Она проверяет автоматический выбор дополнительных композиций, одну горизонтальную фотографию на панораме, фото на 1,5 листа с текстовой колонкой, дату-водяной знак, две тёмные текстовые страницы, градиентное фото-текстовое поле, заполнение текстовых страниц, разлинованную архивную расшифровку и обновление фото при замене.
