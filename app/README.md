# Блоки конструктора (с v166)

`shell.html` — только разметка и порядок подключения. Весь код конструктора разложен по папкам:

| Папка | Что внутри |
|---|---|
| `app/write/` | экран «Писать»: лист-редактор в рамке, вопросы слева, часы, ключи над листом, клавиатура |
| `app/manuscript/` | «Рукопись»: листы, ленточки, «готово», перенос, фото стопкой |
| `app/book/` | «Книга»: просмотр разворотов, дуга миниатюр, правая колонка, композиции, PDF |
| `app/archive/` | старая комната «Семья» и связка с новым архивом (`assets/archive/`) |
| `app/topbar/` | верхние висящие ключи, «Ещё», музыка, подсказки ключей |
| `app/start/` | включение, вход в конструктор, знакомство |
| `app/common/` | общее: цвета, шрифты, день/ночь, мелкие общие правила |

Отдельно и раньше:
- `index.html` + `assets/keeper/` — стартовый экран с Хранителем;
- `sheet_v35.html` + `assets/keeper/sheet-light.js` — сам лист редактора (внутри рамки);
- `assets/archive/` — новый архив;
- `book-renderer/` — движок вёрстки книги.

## Правила

1. Каждый файл подключён ровно там, где раньше стоял его блок: порядок важен, поздние правила перебивают ранние.
   Номер в имени файла (`NNN-…`) — его место в `shell.html`.
2. Правка экрана — только в его папке. В отчёте о сборке перечисляются тронутые файлы.
3. Новое правило — в конец файла своего блока (или новым файлом с номером, вставленным в `shell.html` по месту).
4. Пути к картинкам в CSS — относительно файла: `url(../../assets/...)`.
5. Тесты, которые читают текст страниц, читают их через `qa/lib/page_source.js` (он подставляет файлы обратно).

Разделение сделано механически (`tools/split_shell.py`): содержимое блоков не менялось, обратная сборка совпадает с исходным
`shell.html` побайтно.
