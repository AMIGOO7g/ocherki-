# Design Pack 01 / Book Renderer — отчёт

## Результат

Старый книжный генератор не удалён из проекта, но для дизайна «Редакционный» больше не используется. Новый маршрут состоит из двух независимых модулей:

- `book-renderer/book-engine.js` — детерминированно собирает дерево страниц;
- `book-renderer/design-pack-01.js` + `design-pack-01.css` — рендерят страницы Design Pack 01.

Интерфейс конструктора, структура проекта, загрузка текста и фотографий сохранены.

## Что изменилось принципиально

1. Новый рендерер не использует классы старого книжного дизайна, поэтому поздние CSS-правила конструктора больше не могут увеличивать его шрифты или смещать блоки.
2. Миниатюры, предпросмотр и контрольный каталог вызывают один и тот же `renderPage()`.
3. Смена формата интерфейса не меняет внутреннюю геометрию Design Pack 01: страница остаётся 1000×1000 px, соответствующих 280×280 мм.
4. Алгоритм выбирает только существующие мастера и не создаёт новые композиции.
5. Фотографии читаются из `src`, `dataUrl`, `dataURL`, `url`, `preview` и `objectUrl`.
6. Фотографии не повторяются; пустой фотослот не создаётся для главы без фотографии.
7. Текст не уменьшается автоматически. Остаток переносится на следующий разрешённый мастер.
8. При переключении на «Редакционный» книга пересобирается новым движком, а не только перекрашивается.

## Контрольный каталог

Файл `book-renderer/master-proof.html` показывает для каждого мастера:

- слева — страницу исходного `Style_Proof_v1 cloude.pdf`;
- справа — результат нового Book Renderer;
- сверху — ID мастера и номер страницы-эталона.

На Windows каталог открывается файлом `open_master_proof.bat`.

## Что пока не подтверждено

Пиксельное визуальное совпадение всех мастеров с PDF пока не подтверждено скриншотами. В текущей среде пакет Playwright присутствует, но браузер Chromium отсутствует; его загрузка возвращает пустой повреждённый архив. Облачный браузер по правилам безопасности не открывает локальные файлы проекта.

В архив включены два готовых сценария:

- `qa/capture_design_pack_01.js` — снимает попарный каталог двадцати шести мастеров;
- `qa/run_constructor_capture.js` — нажимает реальные кнопки конструктора и снимает все собранные развороты.

После запуска в среде с установленным Chromium они создадут PNG и `manifest.json`. До просмотра этих PNG нельзя честно объявлять соответствие PDF окончательно принятым.

## Следующий обязательный шаг

Запустить приложенные сценарии в среде с Chromium, сравнить двадцать шесть пар и исправить только обнаруженные координатные расхождения. Архитектурно новый модуль уже отделён; дальнейшие исправления не должны затрагивать конструктор или алгоритм сборки.
