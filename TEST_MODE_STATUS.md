# Общий Engine и Test Mode — статус

15 сентября 2026. Изменения внесены в существующий проект. Test Mode использует исправленный общий двухколоночный Renderer без собственной пагинации.

`shell.html` и `test-mode-runner.js` вызывают одну функцию: `OcherkiLayoutPagination.build(structure, meta)` из `book-renderer/layout-pagination-engine.js`. Страницы в обоих режимах выводит `OcherkiLayoutPagination.renderPage(page, side, meta)`.

Модуль использует существующие `OcherkiBookEngine` и `OcherkiBookRenderer`. Предел текста определяется фактическим DOM через `paginateText` и `splitRenderedText`. Размеры, цикл и привязки существующих композиций находятся в `design-pack-01.layout.js`; HTML мастеров, CSS и шрифты в Test Mode не копируются. Число символов используется только для исходных координат, точного сравнения и диагностики, а не как вместимость.

`meta.composition` прямо вызывает выбранную существующую композицию. Director, оценка содержания, случайный выбор и новые роли не добавлены. Старый отдельный `createEditorialPaginator` удалён из активной цепочки. Исторические алгоритмы других дизайнов остались в файлах, но активный Editorial и Test Mode их не вызывают.

Тестовые данные живут в памяти отдельной страницы. «Очистить» удаляет тестовый результат и фотографии, возвращая исходный просмотр. Test Mode не посылает команды изменения глав и не записывает данные проекта. Ошибка сохраняет последний успешный просмотр; запоздалый результат после очистки игнорируется.

Цитата встроена в реальный измеряемый поток и резервирует центральную полосу до раскладки текста; под ней основной текст запрещён DOM-аудитом. Полевая заметка измеряет фактическую глубину рукописной строки и целиком смещается внутрь безопасной зоны. Прописные акценты являются стилем фраз исходного потока и повторно измеряются вместе с текстом. Абзацные разрывы нормализованы без изменения исходных символов.

## Выполнено

- 30 наборов Node: прежние регрессионные тесты плюс состояние Test Mode, точная сериализация, контракт общего Engine и точечная приёмка v19.
- Проверены точный Unicode/пробелы, неизменность входа, очистка, ошибки, конкурирующие запросы, назначение всех фото, конечность обработки вставок и отсутствие отдельного пагинатора/CSS мастеров в Test Mode.
- 3 HTTP-теста: доступны нужные общие ресурсы, данные проекта и каталоги закрыты, POST-записи нет.

В общий браузерный аудит добавлена отдельная ошибка преждевременного разрыва при свободном месте больше интерлиньяжа. В Test Mode доступны сценарии T1–T26, включая Mobile Apply, desktop/mobile object parity, новую CTX-модель с отдельной secondary-фотографией и отдельную приёмку DARK FADE 2.2 H/V/S.

## Непройденная браузерная приёмка

`check_shared_layout.bat` сравнивает настоящий `shell.html` и исполнитель Test Mode. Сценарии: длинный текст, одно/несколько фото, цитата, рукописная вставка, Unicode, последняя страница и слишком большая вставка; размеры окна 1280 и 375 px, оба формата книги. Проверяются одинаковые HTML/геометрия, ноль потерянных символов, все фотографии и неизменность хранилища проекта.

Сценарий подготовлен, но не выполнен здесь: браузер среды вернул `net::ERR_BLOCKED_BY_CLIENT` до загрузки локального проекта. Поэтому идентичность реального DOM, отсутствие обрезки во всех композициях и мобильный внешний вид пока не подтверждены. Печать/PDF отдельно не проверялись.

Последняя неполная страница закономерно может иметь свободное место: текст не растягивается искусственно.
