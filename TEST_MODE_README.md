# Test Mode на компьютере и телефоне

## Восстановление стабильной базы: T1–T26

Нажмите **«Приёмка T1–T26»**. Test Mode соберёт через рабочий `OcherkiLayoutPagination` мобильный Apply/build path, длинный русский текст, физическое заполнение колонок, рост и уменьшение цитаты, многострочные/переполненные заметки, одинаковые object ID для ПК и телефона, CTX с другой secondary-фотографией и CTX с рукописным fallback, отсутствие CTX при единственном opening photo, DARK FADE H/V/S и полную последовательность главы.

Слева откроется редактируемый диагностический лист T1–T2. В его отчёте показаны `clientWidth`, `scrollWidth`, правая координата контейнера и последнего глифа, свободное место, следующее слово, его измеренная ширина и причина переноса. Автоматический visual wrap не сериализуется в исходный текст.

Отдельная кнопка **«Приёмка DARK FADE 2.2»** показывает H, S и V на трёх разных фотографиях. Во всех состояниях используется исходный `<img>`, отдельный тёмный фон и CSS alpha-mask; цветовой фильтр отсутствует.

Включите **«Показывать диагностику»**. Для текущего разворота выводятся `spreadId`, `templateId`, `sourceTextHash`, `objectId`, `objectType`, `pageIndex`, геометрия и флаги видимости desktop/mobile, а также общий engine/renderer/paginator, результаты T1–T26 и предупреждения. Для длинной полевой заметки используется сообщение: «Заметка слишком длинная для этой области. Сократите текст.»

## Локальный запуск

1. Распакуйте ZIP целиком; нужен Python 3.9 или новее.
2. Запустите `start_test_mode.bat`.
3. На компьютере откройте адрес из окна запуска. Телефон подключите к той же Wi‑Fi сети и откройте строку «На телефоне».
4. Для собственного материала нажмите «Тестовый текст», вставьте текст и фотографии, затем «Применить».

ПК и телефон получают одну и ту же книжную модель 1000 × 1000 или 1000 × 1196. Отличается только масштаб интерфейса; порядок разворотов, переносы, цитаты, заметки, акценты, фотографии, CTX и DARK FADE не зависят от viewport.

Test Mode не записывает временный материал в проект. Для проверки сохранённой копии используйте «Материал → Сохранённая копия проекта».

Автоматические проверки: `node qa/v40_precision_corrections_test.js`, остальные `qa/*_test.js` и `python -B qa/test_mode_server_test.py`. Полный технический отчёт находится в `PRECISION_CORRECTIONS_V19_REPORT.md`.
